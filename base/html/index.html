Promoted by Kargo, deployed by Argo CD

This page is served by nginx from a ConfigMap generated by Kustomize. Change a file in base/html/ or bump the nginx image and watch the change move through dev, qa and prod.

site version: v2

1. Commit

Edit the HTML on main. Kargo's Warehouse notices the new commit and creates Freight.

2. Promote

Kargo renders the manifests for a stage and opens a pull request against its stage branch.

3. Sync

After you merge, Argo CD syncs the stage branch and rolls the pods.
